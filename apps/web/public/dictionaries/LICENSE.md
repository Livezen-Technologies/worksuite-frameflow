# Sinhala and Tamil word lists

Used for typing suggestions and spell check. One word per line; replace
either file with a list of the same format to change the dictionary.

## si.txt — Sinhala (CC BY-SA 4.0)

From FrequencyWords by Hermit Dave
(https://github.com/hermitdave/FrequencyWords), `content/2018/si/si_full.txt`,
built from the OpenSubtitles 2018 corpus (http://opus.nlpl.eu/OpenSubtitles2018.php).
Most frequent first. Changes: counts removed; only words written wholly in
Sinhala script kept.

Licence: Creative Commons Attribution-ShareAlike 4.0 International,
https://creativecommons.org/licenses/by-sa/4.0/. The licence covers this
file only.

## ta.txt — Tamil (MIT)

From open-tamil by the Ezhil Language Foundation
(https://github.com/Ezhil-Language-Foundation/open-tamil),
`solthiruthi/data/tamilvu_dictionary_words.txt` (headwords of the Tamil
Virtual Academy dictionary). Alphabetical, not by frequency. Changes: only
words written wholly in Tamil script kept, duplicates removed.
